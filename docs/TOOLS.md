# Open-source components

The assignment explicitly permits/encourages free/open-source tooling.

- Terraform — HashiCorp
- K3s — Rancher/SUSE
- OWASP Juice Shop — OWASP project
- Wazuh — open-source security platform
- WireGuard — open-source VPN
- ModSecurity + OWASP CRS — open-source WAF stack
- Trivy — open-source security scanner
- Gitleaks — open-source secret scanner

Third-party images and scripts are pinned where practical. Re-check upstream release compatibility before the assessment run.
